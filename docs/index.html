🚀 Szybki start

Calisto Vault to nowoczesny, bezpieczny menedżer haseł działający na Windows i Android z opcjonalnym wsparciem dla pendrive MASTER oraz synchronizacją P2P.

Główne cechy:

  • 🔒 Pełne szyfrowanie (AES-256-GCM)
  • 🔑 KDF: Argon2id
  • 🗃️ Baza danych: SQLCipher
  • 💾 Pendrive MASTER: fizyczny klucz bezpieczeństwa
  • 🔄 Synchronizacja P2P: bez serwera, bez chmury
  • 📱 Autofill na Androidzie
  • ✅ Działanie offline
