📱 Aplikacja Android

Aplikacja Calisto Vault na Androida oferuje:

  • ✅ Przechowywanie haseł w zaszyfrowanej bazie Room
  • ✅ Synchronizacja z Cloudflare Workers (opcjonalnie)
  • ✅ Synchronizacja P2P między urządzeniami
  • ✅ Autofill API - automatyczne wypełnianie formularzy
  • ✅ Tryb offline - działa bez internetu
  • ✅ Ciemny motyw z akcentami fioletowo-złotymi

Wkrótce dostępne na GitHub Releases!

Buduj z źródeł: ./gradlew assembleRelease

❓ FAQ

Czy to jest naprawdę darmowe?

✅ Tak! Wszystkie używane technologie (Android SDK, Cloudflare Pages, Workers, KV Storage) mają darmowe plany, które w zupełności wystarczą dla większości użytkowników.

Czy moje dane są bezpieczne?

✅ Tak! Wszystkie dane są szyfrowane lokalnie (AES-256-GCM) przed wysłaniem. Cloudflare zapewnia HTTPS i ochronę DDoS.

Czy muszę używać Cloudflare?

❌ Nie! Aplikacja działa w 100% offline. Cloudflare to opcjonalna warstwa synchronizacji.

Czy jest wersja na iOS?

❌ Nie, obecnie tylko Android. iOS w planach na przyszłość.
